SMART BARCODE ATTENDANCE SYSTEM
================================
project/index.html            -> open this in Chrome/Edge to run the project
project/css/style.css         -> all styles
project/js/script.js          -> all application code (students, scan, reports, graphs, backup)
project/smart-barcode-attendance-single-file.html -> same project in ONE file (easiest to share)
reports/                      -> two Word project reports
diagrams/                     -> workflow, architecture, DFD 0/1, ER diagram (PNG)

Run: open project/index.html. Needs internet once for JsBarcode and html5-qrcode libraries.
Dashboard -> "Load demo dataset" fills 40 students + 3 weeks of attendance.
Camera scanning needs HTTPS or localhost; a USB scanner works anywhere.
Before submitting reports: replace [Student Name], [Roll No], [Guide Name], add screenshots.
